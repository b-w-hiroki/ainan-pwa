## 現時点の証拠／不採用理由

- PR #126: 広域Teleaで海・桟橋がにじむため不採用。
- PR #138: 同じ高さの海を単純コピーし、足元の桟橋まで海になるため不採用。
- PR #151: 水・桟橋の材質別補完候補。隠れた実構造の正しさは未検証。
- PR #156: 水と桟橋の境界・穴の外周を可視化。レビューCI成功だが素材承認ではない。
- PR #157: 桟橋境界 -6/0/+6px を同条件比較。境界移動だけでは足元の破綻が解消しない。
- 対応すべき失敗分類は「空間パース／欠損補完／人物輪郭／手・竿接続」。単純な色移植・境界移動だけで再生成を繰り返さない。

## 作業を戻すルール

- H03で桟橋の構造が破綻したら H02へ戻す。色調整だけで合格にしない。
- H04で髪や足元のhaloが出たら H04をやり直す。H03の背景への貼付で隠さない。
- H05で竿が二重になる場合、手元のpivot／owner契約を見直す。
- H07以降でモック劣化・保存回帰・入力不具合が出たら本番への昇格を停止し、原因工程とその依存工程を再QAする。
