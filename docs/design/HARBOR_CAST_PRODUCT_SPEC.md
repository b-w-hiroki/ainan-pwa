# AINAN 港釣り画面｜体験・画面仕様（ドラフト）
更新: 2026-10-15 / 対象 Issue #140（背景・人物）/#118（横画面）/#108（魚・釣り場）

## 目的
キャストすると釣り人から視線が沖へ移り、ルアーの飛行にあわせてカメラが追従し、見えていた画面の外側へ海が広がる体験を作る。既存の承認済み縦画面およびセーブ・釣獲率を変更しない。新構図は**試作扱い**で、承認までは本番表示に入れない。

## 操作と状態
1. 待機: 足場先端寄りのプレイヤーと広い海を表示。初期方向は画面左下から斜め右上へ。
2. キャスト準備・振りかぶり: プレイヤーと竿先を見せ、入力に応じて飛距離・方向を決定。入力可能範囲は既存操作に合わせる。
3. リリース・飛行: カメラはプレイヤー固定から竿先の動きに重みを移し、ルアーを追う。ルアーが旧ビューポート外に出てもワールド上の飛行と追従を継続する。カメラの移動と拡張背景によって海の距離を感じる（単純な背景拡大や静止画スライドで代替しない）。
4. 着水: カメラを着水点基準に減速して落ち着かせ、波紋・ライン・着水位置を読めるようにする。
5. 巻取り/HIT/Battle/Result: 既存の釣りループを維持。巻取りに応じてカメラはプレイヤー側へ自然に復帰し、画面切替時に急なジャンプを出さない。
6. 中断・再開・画面回転: アニメーション二重生成や入力重複を防ぎ、ワールド位置を維持してUIのみ再配置できる。

## キャスト安全領域
竿先から飛行軌道・巻取り直線および竿のスイング範囲に障害物を配置しない。桟橋は足場のみにとどめ、係船柱・手すり・柱・船・看板・ロープ・猫などは安全領域外へ。射線が視覚的にも遮られないことをレビューし、装備別の竿長差でも再検証する。物理判定もこの領域を共有する。

## 差し替え要件
プレイヤーの性別/体型表現、服装（帽子・上衣・下衣・靴・鞄）、竿/リール、オプション（猫等）を独立パーツとして変更できる。待機・キャスト・着水・巻取り・HIT間で装備が消えたり描画重複しない。猫はプレイヤー後方の安全位置に配置する。糸・ルアーはプレイヤー装備絵へ焼き込まず、既存描画ownerを維持する。

## アートと画面
背景を空/山/町、海面（奥行き・波・反射）、桟橋足場、可動プレイヤー、服装、竿、ライン/ルアー、オプション、UIに分離。海側にカメラ移動量を超えるワールドの余裕を持たせる。390×844は承認済み画面とのBefore/After比較を必須とし、844×390・932×430は #118 の別gate。44 CSS px操作ターゲットとsafe-areaを維持。
