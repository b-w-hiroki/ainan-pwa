# AINAN Environment & Economy Spec

## Environment model

AINANの天候は**実際の現在地の天気ではなく、ゲーム内の日替わり天候**として扱う。

- 季節: 端末の日付から春 / 夏 / 秋 / 冬を決定
- 時間帯: 端末時刻から朝 / 昼 / 夕 / 夜を決定
- 天候: 年月日から決定論的に晴れ / くもり / 雨を生成
- 同じ日なら同じ天候になり、API通信・位置情報・外部サービスに依存しない
- 季節 / 時間帯 / 天候は魚の出現ウェイトと釣り画面の演出に反映する

### 採用理由

1. 魚の出現条件を再現しやすく、攻略情報として成立する
2. オフラインPWAでも同じ遊びを維持できる
3. 位置情報や外部天気APIがなくてもテスト可能
4. 「今日は雨だからこの魚を狙う」という日替わり動機を作れる

将来リアル天候と連携する場合も、ゲーム内天候をフォールバックとして残す。

## Economy targets

現行の秋 / 昼 / 晴れ / 基本エサを基準に、3釣り場の期待獲得値を平均すると約 **473pt / 1釣果**。

| プレイ想定 | 釣果数 | 釣果ポイント概算 | 狙い |
|---|---:|---:|---|
| 初回約1時間 | 12匹 | 約5,700pt | 町の序盤解放 + 最初の強化を体験 |
| 累計約3時間 | 30匹 | 約14,200pt | 中盤施設・竿強化・アクセサリを選択 |
| 長期100釣果 | 100匹 | 約47,300pt | 主要育成を完走可能 |

主要な恒久育成シンクは約 **28,500pt**。

- 町施設 Lv.5 × 4: 約16,800pt
- 全竿 Lv.5 + 高級竿購入: 約10,500pt
- アクセサリ2種: 1,200pt

ミッション、魚屋売却、ボス報酬で実収入はこの概算より増えるため、実機テストでは「3時間以内に全要素を買い切れないこと」を重点確認する。

## Balance guardrails

- 初回1時間で主要恒久育成の30%を超えない
- 累計3時間で主要恒久育成の65%を超えない
- 100釣果程度なら主要恒久育成を完走可能
- 魚屋は追加収入だが、釣った瞬間の報酬より高くしない
- 料理は消費先として機能し、恒久強化を置き換えない
- ボス報酬は節目の加速要素であり、通常釣果を無意味にしない

これらは `scripts/final-polish-smoke.mjs` で継続監視する。
