# 漁港・キャラクター素材原本

2026-10-16、内蔵 image_gen で生成した最新候補11枚を格納。
PNGと生成プロンプトを対で保存。原本のピクセルは変更していません。
`index.html` は透過確認用の一覧、`manifest.json` は寸法・アルファ・可視範囲・SHA-256の検査結果です。

## 内容

- `harbor-morning`：漁港全体の構図参照
- `harbor-distant-layer`：遠景。下部は不透過の無地であり、そのまま海に重ねる用途には不適合
- `harbor-sea-layer`：海のみ
- `harbor-pier-layer`：桟橋と係船柱
- `harbor-props-layer`：木箱とロープ巻き
- `W02-OPENSEA`：外海
- `water-effects-sheet`：波紋3種類、水しぶき、きらめき
- `W03-BODY-{A,B}-{idle,windup}-v2`：素体A/Bの待機・振りかぶり

## 未解決事項

全11枚が指定寸法と異なります。背景は3072×2048、演出シートは2048×1024、人物は1024×1024が目標です。拡大だけでは描画情報は増えません。
人物の足元と各背景レイヤーの輪郭には生成時のずれがあり、厳密な位置合わせは未完了です。
アルファチャンネルと透明ピクセルの存在は検査済みですが、輪郭の色残りや半透明のにじみは別途目視修正が必要です。
桟橋・小物は最大アルファ254、水面演出は252です（255が完全不透明）。原本の特性として保持しています。
水面演出シートは各効果の切り出し矩形と余白の確定が必要です。
ゲーム本体のロード対象には追加していません。完成済み・実装済み素材として扱わないでください。
