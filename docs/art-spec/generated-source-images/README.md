# Generated fishing images

This folder keeps browsable PNG snapshots of the fishing-field art parts created during the September 2026 visual pass.

- PNG archive: `docs/art-spec/generated-source-images/files/`
- Runtime/editable assets: `fishing-game/assets/fishing-field/`
- Source-to-runtime mapping: `docs/art-spec/GENERATED_ASSET_PROVENANCE.md`

The PNG files are generated from the managed production assets so the artwork can be reviewed directly in GitHub while runtime code continues to use lightweight animation-friendly SVG parts.
