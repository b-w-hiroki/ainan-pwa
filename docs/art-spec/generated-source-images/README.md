# Generated source images

This folder preserves the generated fishing-field source images used during the September 2026 visual pass.

`source-images.zip` contains 19 image files. A GitHub Actions workflow extracts them into `files/` so each image is browsable in the repository.

The archived images are optimized source snapshots for repository management; runtime code continues to use the lightweight production assets under `fishing-game/assets/fishing-field/`.
