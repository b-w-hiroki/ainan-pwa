# AINAN Fishing Field — Minimum Asset Generation Prompts

These prompts are for **production-oriented game parts**, not concept art.

Common style rules:

- casual Japanese mobile-game style
- clean simple 2D rendering
- moderate stylization
- readable at phone size
- animation-friendly
- no text
- no frame/border
- avoid photorealism
- avoid excessive detail
- when transparency is requested, use a transparent background

# Recommended generation order

Generate and evaluate these five first:

1. `water_base_01`
2. `fish_shadow_m_idle_01`
3. `lure_idle_01`
4. `fx_ripple_small_01`
5. `retrieve_button_short_reel_01`

First verify these five together on a 390×844 mock screen. Only then produce the remaining water layers, fish sizes, turn state, lure motion assets, FX, and secondary UI pieces.

This avoids producing a full asset set before the core visual language is proven.
