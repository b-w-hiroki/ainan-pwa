# Game Asset Directory

This folder contains generated and hand-authored art assets for the Phaser fishing game.

## Structure

- `backgrounds/` - full-screen scene backgrounds
- `characters/` - character cutouts and NPC art
- `fish/` - fish icons and result art
- `ui/` - frames, pins, badges, signs, and decorative UI parts
- `references/` - local reference exports used for art direction only

## Naming

Use lowercase snake case.

Examples:

- `bg_title_harbor_morning.png`
- `bg_map_town.png`
- `bg_fishing_harbor.png`
- `ch_guide_default.png`
- `ch_player_default.png`
- `fish_madai_icon.png`
- `ui_spot_pin_harbor.png`

## Rules

- Do not bake game UI text into images.
- Do not include real place names or municipality branding.
- Prefer crisp silhouettes and warm colors.
- Keep source prompts and notes in `docs/VISUAL_DIRECTION.md`.
